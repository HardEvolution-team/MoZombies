# Mo' Zombies Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **Mo' Zombies** by coocoo617.

- Original: https://www.millenium.org/guide/117759.html
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.35.0+

This port contains **no original assets**. Put your own copy of the original jar (`mo_zombies_2.1.0.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
